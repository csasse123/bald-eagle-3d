# Bald Eagle 3D

[Open the interactive anatomy viewer](https://csasse123.github.io/bald-eagle-3d/)

An interactive adult bald-eagle anatomy model developed with Christian Sasse’s photographic references. The page opens on the whole assembled eagle with **All** layers enabled. Reset returns to the same default.

Drag to rotate, scroll or pinch to zoom, and click a structure to inspect it. **Internal organs** and **Muscles & tendons** are in the anatomy sidebar with the layer controls. Use the muscle-region selector to examine the shoulder, wing, neck, trunk, or leg-to-toe routes. **Hide controls** (or H) clears the overlays; the same button restores them. There is no opaque base or floor ring. Above and Below show both feather surfaces, with rebuilt underside coverts and balanced illumination. Opaque skin and plumage naturally cover internal structures in the assembled view.

Read the [muscle and tendon research notes](ANATOMY-RESEARCH.md) for sources, implemented relationships, and reconstruction limits.

This publication contains the anatomy studio. The separate experimental Flight Lab and slow-motion videos are not included.

## Running the viewer

Use the link above in a current WebGL-capable browser. A desktop or laptop is recommended for this detailed model. The first download is approximately 53 MB and building the geometry takes a little time. There is no account, installation, or build step.

`index.html` also works as a downloaded standalone file. Its renderer, controls, textures and photographic comparisons are embedded; no CDN is required. The cited reference links require internet access.

## Model and image credits

This is a procedural educational reconstruction, not a specimen scan or a validated physiological simulation. The viewer includes anatomical references and explains which dimensions, feather samples and movements are reconstructed. Selectable component counts are a model inventory, not a biological census.

Christian Sasse’s photographs and the supplied comparison references retain their existing credits. Additional comparison photographs are identified in the viewer’s sources.
